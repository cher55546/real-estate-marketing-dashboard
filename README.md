# Маркетинговая аналитика жилой недвижимости

Интерактивный дашборд для анализа эффективности рекламных каналов девелопера.

## О проекте

Проект демонстрирует анализ маркетинговых расходов, объема обращений и продаж с использованием синтетических данных за 2025 год.

Дашборд позволяет оценивать:

- стоимость привлечения обращений;
- стоимость квалифицированного лида;
- конверсию этапов воронки;
- стоимость сделки;
- выручку;
- ROMI по каналам;
- динамику расходов и обращений.

Датасет содержит следующие показатели:

- рекламный канал;
- название кампании;

- квалифицированные обращения;
- встречи и показы;
- бронирования;
- сделки;
- выручка.

## Расчёт метрик

```text
CPL = Расходы / Обращения
Стоимость сделки = Расходы / Сделки
ROMI = (Выручка - Расходы) / Расходы
Конверсия лидов = Сделки / Обращения
```

Дополнительные конверсии рассчитываются для последовательных этапов воронки:

```text
Обращения -> Квалифицированные обращения
Квалифицированные обращения -> Встречи
Встречи -> Бронирования
Бронирования -> Сделки
```

Для расчёта используются защитные проверки от деления на ноль.

## Источник данных

Все данные в проекте синтетические и сгенерированы детерминированно в Google Colab с фиксированным seed.

Данные не содержат реальных рекламных кампаний, компаний, клиентов или коммерческих показателей.

ROMI рассчитывается на уровне агрегированных синтетических продаж и не является прогнозом реальной доходности.
